webhost-apps · shared UI

share-kit

One shared capability-share UI for the whole app suite — the Share button, the capability receipt (link + plain-English scope + Revoke + status pill), and the recipient banner. Same shape across timeline-peek, calendar-share and otterpilot, so learning one app teaches all of them. Inherits each app's own pod inking.

owner view · watermelon classic

Share action + capability receipt

Click Share — the kit "mints" a scoped link (fake, no backend here), then renders the receipt: the ?token= URL, a TRUE scope sentence, a copy control, and Revoke. Revoke flips the pill to revoked and disables itself. In a real app onShare performs the mint and onRevoke performs DELETE /api/tokens/:t.

recipient view · the three honest end-states

Recipient banner

The top strip a recipient sees. active names the owner and the capability plainly; revoked / expired / gone are honest end-states — never a silent stall. (The live one is pinned to the top of this page.)

token inheritance · same kit, app's own inking

Re-inked: grape acid (webhost register)

This panel overrides the pod tokens for its subtree only. share-kit consumes var(--ink1) / var(--ink2) / …, so the very same receipt and banner render in the host app's inking with zero code change — that's the whole point of the kit.
