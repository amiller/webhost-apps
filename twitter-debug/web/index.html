④ Reification — blind API vs browser-observed truth the point

Same intent — read your home timeline — three ways. The blind API guesses the request; the browser observes the real one X's own JS signs; reify replays that capture headlessly (no browser). The browser is spent once, then the call is cheap and repeatable.
