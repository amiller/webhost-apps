the brainrot box

It listens to the room and paints it. A judge reads the transcript and when somebody lands a banger, the canvas flashes the quote and writes it in a ledger. The meeting gets a score now.

▶  open the box works on any laptop · 🎤 mic or a live Otter feed · nothing to install

the two models

One box that paints the room while little detectors read it.

the canvas · paints
toolsmith × compositor
two models in TEE enclaves · NEAR + Chutes
  • toolsmith writes little animation tools, live
  • compositor VJs them, 2–5 layers a frame
  • e2ee prompts decrypt only inside the enclave
the detectors · read
judge · decoder · distill
every few seconds, over the same transcript
  • judge scores the last minute: quote · why · 0–10
  • decoder types the talk into the topic timeline
  • distill turns the mood into a visual brief

speech via your 🎤 or a scoped, revocable Otter read token — no raw mic upload, no copied cookies

room speech → transcript → judge · decoder · distill → brief → toolsmith writes a tool → compositor stacks 2–5 layers → canvas

the loop

Complain about the box to the box. It ships the fix overnight.

in the meeting
Feedback and ideas are just… said out loud. Nobody files anything.
transcript lands
An intake pass reads finished Otter transcripts through the same scoped token, looking for feedback to act on and work worth taking.
before acting
The swarm posts a Matrix warning of what it's about to take on — reply veto within the window to stop it.
by morning
Accepted items come back as evidence-gated fixes: coding agents work them overnight, and a screenshot gate proves each one before it merges.

Prompts decrypt only inside the model's enclave — the inference provider's gateway and the network path never see a word. Runs on an attested CVM.
